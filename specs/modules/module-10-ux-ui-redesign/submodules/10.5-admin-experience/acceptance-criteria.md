# Criterios de aceptacion 10.5

- [x] El dashboard admin muestra estado general con datos reales.
- [x] La pagina de metricas agrupa informacion y traduce estados visibles.
- [x] Usuarios muestran nombre, correo, rol, estado, filtros y accion existente.
- [x] Profesionales muestran nombre, correo, publicacion, usuario activo y acciones existentes.
- [x] Reservas muestran fecha, modalidad, estado y filtros reales sin inventar nombres.
- [x] Catalogo separa categorias y especialidades, con formularios y acciones existentes.
- [x] Loading, error y empty states usan componentes globales.
- [x] Las tablas tienen alternativa responsive tipo cards en mobile.
- [x] No se modifica backend, permisos ni guards.
- [x] No se exponen datos sensibles nuevos.
- [x] El build frontend finaliza correctamente.
