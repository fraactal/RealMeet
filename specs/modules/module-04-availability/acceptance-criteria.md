# Criterios de aceptacion del Modulo 4

| ID | Criterio | Estado |
| --- | --- | --- |
| AC-M4-001 | Un profesional puede listar sus reglas semanales. | implementado |
| AC-M4-002 | Un profesional puede crear una regla valida. | implementado |
| AC-M4-003 | Una regla con inicio igual o posterior al termino es rechazada. | implementado |
| AC-M4-004 | No se permiten reglas solapadas para el mismo profesional y dia. | implementado |
| AC-M4-005 | Un profesional no puede modificar reglas de otro profesional. | implementado |
| AC-M4-006 | Un profesional puede editar o eliminar una regla propia. | implementado |
| AC-M4-007 | Un profesional puede listar sus bloqueos. | implementado |
| AC-M4-008 | Un profesional puede crear un bloqueo valido. | implementado |
| AC-M4-009 | Un bloqueo con rango invalido es rechazado. | implementado |
| AC-M4-010 | Un profesional no puede modificar bloqueos de otro profesional. | implementado |
| AC-M4-011 | La consulta publica devuelve slots segun reglas activas. | implementado |
| AC-M4-012 | Los slots bloqueados no se devuelven. | implementado |
| AC-M4-013 | Los slots pasados no se devuelven. | implementado |
| AC-M4-014 | Los slots respetan la duracion configurada. | implementado |
| AC-M4-015 | Las fechas sin disponibilidad devuelven lista vacia. | implementado |
| AC-M4-016 | La consulta limita rangos excesivos. | implementado |
| AC-M4-017 | Los slots se devuelven ordenados. | implementado |
| AC-M4-018 | La interfaz profesional permite administrar reglas y bloqueos. | implementado |
| AC-M4-019 | El detalle publico permite consultar horarios. | implementado |
| AC-M4-020 | No se crean reservas en este modulo. | implementado |
| AC-M4-021 | Los permisos se aplican en backend. | implementado |
| AC-M4-022 | `/health` y `/ready` continuan funcionando. | aprobado |
| AC-M4-023 | El frontend compila. | aprobado |
| AC-M4-024 | Las pruebas backend minimas pasan. | aprobado |
| AC-M4-025 | La matriz de trazabilidad esta actualizada. | implementado |
| AC-M4-026 | Existe un unico commit final del modulo. | aprobado al cierre |
